# VPN-пулы для Happ и Incy

GitHub Actions каждый час загружает открытые конфигурации, объединяет их по назначению, проверяет TCP-доступность адресов со стороны GitHub Actions и публикует два небольших списка с наименьшей измеренной задержкой:

- `docs/normal.txt` — до 5 обычных серверов;
- `docs/whitelist.txt` — до 10 серверов для белых списков.

Для клиентов, которым нужен Base64, рядом создаются файлы `.base64`. `subscription.txt` содержит объединение выбранных серверов.

## Источники

- Обычный пул: `BLACK_VLESS_RUS.txt` от igareck и проверенные группы обычных серверов из `tiagorrg/vless-checker`.
- Пул белых списков: `final_sorted` от all_subs, `WHITE-CIDR-RU-checked.txt` от igareck и проверенные `w_*` группы из vless-checker.
- Репозитории `Amberpiclippers/vpn-configs-for-russia-region` и `TempestTerrapin/vpn-russia-obhod-whitelists` не используются: в проверенной структуре вместо явных текстовых подписок присутствовали подозрительно названные бинарные файлы и исходники.

Список проверяется каждый час из сети GitHub Actions. TCP-проверка отбирает доступные порты и измеряет задержку до них; это не проверка VPN-авторизации и не гарантирует такую же скорость из сети пользователя. Если актуальных проверенных серверов меньше заданного максимума, подписка будет короче, без повторов одного адреса.

Страница подписок: <https://alex12571333.github.io/vpn/>.
