# Моя общая подписка для Happ и Incy

Скрипт собирает публичные текстовые подписки из трёх источников, оставляет поддерживаемые URI-конфигурации, удаляет точные дубликаты и сортирует список по протоколу, имени сервера и адресу.

## Источники

- `solovyov-jenya2004/all_subs` — `final_sorted`.
- `igareck/vpn-configs-for-russia` — `BLACK_VLESS_RUS.txt` и `WHITE-CIDR-RU-checked.txt`.
- `tiagorrg/vless-checker` — опубликованный `docs/keys.json`.

Источники `Amberpiclippers/vpn-configs-for-russia-region` и `TempestTerrapin/vpn-russia-obhod-whitelists` пока не включены: на момент подготовки в их корне вместо файлов подписки видны случайно названные исполняемые файлы/исходники и архивы с паролем. Скрипт не скачивает бинарники и архивы. Добавляйте источник после проверки конкретного открытого текстового файла с URI-ссылками.

## Локальный запуск

Нужен Python 3.10+; сторонние пакеты не требуются.

```sh
python3 update_subscription.py
```

Результаты появятся в `docs/`:

- `subscription.txt` — обычный список URI, по одному на строку;
- `subscription.base64` — тот же список в Base64;
- `status.json` — время обновления, количество серверов и ошибки источников.

Если источники временно недоступны и не получено ни одной конфигурации, скрипт завершится с ошибкой и не перезапишет ранее собранную подписку.

## Публикация одной ссылки

Workflow обновляет список каждый час и выкладывает `docs/` на GitHub Pages. Загрузите этот проект в свой GitHub-репозиторий, затем в настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника публикации. После первого успешного запуска ссылки будут:

- `https://ВАШ-АККАУНТ.github.io/ИМЯ-РЕПОЗИТОРИЯ/subscription.txt`
- `https://ВАШ-АККАУНТ.github.io/ИМЯ-РЕПОЗИТОРИЯ/subscription.base64`

Добавьте нужную ссылку в Happ или Incy как URL-подписку. Для проблем с импортом попробуйте второй формат.

## Важно

Это агрегатор открытых конфигураций третьих лиц, а не собственный VPN-сервис. Состав и доступность серверов меняются; проверка источника не гарантирует безопасную эксплуатацию его узлов. Для домашней публикации избегайте добавления закрытых или персональных ключей.
